Serveurs d'outils (MCP)

Des serveurs MCP qu'une conversation peut choisir dans « Outils ». Une liste JSON : [{"name": "fichiers", "command": "npx", "args": ["…"], "description": "…", "read_only": false}]. Pas de clé ici : ce fichier ne garde aucun secret.

Alertes par ntfy (appli de notifications externe, facultatif)

Les notifications du navigateur se règlent sur chaque appareil (« Notifications »). ntfy est une autre appli : le texte de l'alerte passe en clair par son serveur, et quiconque connaît le sujet la reçoit. Choisissez un sujet long et impossible à deviner.

Paquet de départ

L'IA de résumé raccourcit le résumé, puis les derniers échanges sont abrégés. Cela consomme un peu de son quota.

Vous retouchez le résumé et choisissez les échanges gardés.

Appareils connectés

Chaque ligne est une session ouverte. Un téléphone perdu : déconnectez-le ici, ou « Déconnecter tous les autres ».

Travail autonome

L'IA travaille seule vers l'objectif : à chaque tour elle avance, vérifie, puis dit si c'est fini. Elle s'arrête quand c'est fini (et que la vérification passe), ou à une limite. Le mode de permission de la conversation reste appliqué : en manuel, chaque action vous sera demandée.

Outils de l'IA dans cette conversation

Un outil « lecture seule » est utilisé sans vous demander. Les autres suivent le mode de permission de la conversation. Les serveurs d'outils se déclarent dans « Réglages ».

Tâches planifiées de cette conversation

Une tâche se relance seule, dans cette conversation (son dossier, son IA, son mode de permission). Le serveur doit tourner : une heure manquée pendant que le PC dormait est rattrapée une fois.
